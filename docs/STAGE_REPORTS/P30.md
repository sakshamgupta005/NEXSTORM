## 1. Executive Summary

P30 integrates multimodal AI image analysis directly into NEXSTORM's existing road-risk and building-exposure engines. Following the strict requirement **not** to build a detached image-analysis product or new risk API family, visual observations are extracted, validated against strict Zod schemas, and deterministically mapped into versioned `VisualRiskFeaturesV1` application records.

The pipeline adheres strictly to all core hydrometeorological guardrails:
1. **No LLM Risk Score Hallucination:** LLMs are restricted to structured visual observations (`roadWaterCondition`, `roadPassability`, `buildingWaterImpact`). Final risk elevations and route impedance penalties are computed via deterministic TypeScript rules.
2. **Confidence Calibration:** Raw model confidence is treated as uncalibrated and scaled by image quality factor and spatial accuracy.
3. **No Depth Fabrication:** Ordinary photographs cannot measure millimeter water depth; only qualitative condition proxies relative to physical objects (curbs, doorsteps, vehicle axles) are extracted.
4. **No GPS Inference from Pixels:** Location bindings require authenticated coordinates or explicit snapping; models never guess coordinates or building IDs from appearance.
5. **Strict Temporal Stratification:** Historical surveys (`isHistorical: true`) are classified as `historical_vulnerability_only` and never trigger active route closures or emergency warnings.
6. **Graceful Handling of Edge Cases:** Provider failures, corrupted images, and ambiguous photos are rejected without fabricating false alarms or false safety claims.
7. **Deduplication:** Repeated uploads are deduplicated using SHA-256 hashes.

export const visualObservationZodSchema = z.object({
  sceneType: z.enum(['street_level', 'aerial', 'satellite', 'unknown']),
  visibleWaterOnRoad: z.boolean(),
  roadWaterCondition: z.enum([
    'none',
    'curb_ponding',
    'flowing_surface_water',

    'none',
    'water_at_perimeter',

    'ground_floor_flooded',
    'unknown',
  ]),
  waterExtent: z.enum(['none', 'localized_spot', 'corridor_linear', 'areal_broad', 'unknown']),
  imageQuality: z.enum(['high', 'adequate', 'poor_blurry_dark', 'occluded']),
  occlusionDegree: z.enum(['none', 'partial', 'heavy']),

  rawEvidenceExplanation: z.string().min(5).max(1000),
  modelConfidence: z.number().min(0).max(1),

## 4. Deterministic Mapping to Versioned Risk Features

The `VisualRiskFeatureMapper` (`src/lib/images/risk-mapper.ts`) translates observations into `VisualRiskFeaturesV1`:

- **Road Hazard Rule:**
  - `impassable` or `submerged` or `deep_standing_water` &rarr; `currentRoadRiskElevation: 'high'`, `routeImpedancePenalty: 30`.
  - `caution` or `flowing_surface_water` &rarr; `currentRoadRiskElevation: 'moderate'`, `routeImpedancePenalty: 15`.
  - Otherwise &rarr; `currentRoadRiskElevation: 'none'`, `routeImpedancePenalty: 0`.
- **Building Hazard Rule:**
  - `entrance_doorstep_inundation` or `ground_floor_flooded` &rarr; `currentBuildingExposureElevation: 'high_catchment'`.
  - `water_at_perimeter` &rarr; `currentBuildingExposureElevation: 'moderate_catchment'`.
- **Weight Calibration:**
  $$\text{calibratedWeight} = \text{modelConfidence} \times \text{qualityFactor} \times \text{spatialFactor}$$
  where $\text{qualityFactor} \in \{1.0, 0.8, 0.5\}$ and $\text{spatialFactor} \in \{1.0, 0.75\}$.
- **Historical Safeguard:**
  - If `isHistorical: true`, `temporalRelevance` is locked to `'historical_vulnerability_only'`, and all active elevations and penalties are set to 0.

## 5. Integration with Existing Risk Pipelines

1. **Road Risk Pipeline (`roadRiskService.evaluateSegmentRisk`):**
   - Ingests `RoadImageEvidenceSummary` including `riskFeatures`.
   - If active verified flooded imagery exists (`floodedRoad: true` or `passability === 'impassable'`), elevates `dynamicRiskClass` to `'high'`.
2. **Route Calculation Pipeline (`roadRiskService.evaluateCandidateRoutes`):**
   - Applies deterministic impedance penalty (up to 30 points per segment).
   - Sets recommendation to `'avoid'` with detailed explanation when traversing visually inundated segments.
3. **Building Exposure Pipeline (`buildingExposureService.evaluateFootprintExposure`):**
   - Ingests `BuildingImageEvidenceSummary` including `riskFeatures`.
   - If active image confirms inundation, elevates `dynamicExposureCategory` to `'high_catchment'`.

## 7. Limitations & Blocked Capabilities

1. **Remote Cloud Model Access Without API Keys:**
   - When neither `GOOGLE_GENERATIVE_AI_API_KEY` nor `OPENAI_API_KEY` is set, the system falls back seamlessly to the deterministic local rule-based extractor.
2. **FloodNet Drone vs. Street-Level Perspective Shift:**
   - Multi-perspective awareness is enforced: nadir/aerial models are not assumed reliable for ground-level camera angles.
3. **Satellite Real-Time Limitations:**
   - Optical satellites (Sentinel-2) are 100% cloud-blind during active monsoon downpours. Synthetic Aperture Radar (Sentinel-1) has a 12-day revisit interval, making it unsuitable for 1-hour early warning.
