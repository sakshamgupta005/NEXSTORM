## 1. Executive Summary

P31 integrates image-derived visual evidence directly into the **actual, existing scoring calculations** for road network risk, route evaluation, and building flood exposure. Rather than creating a detached secondary scoring system or separate dashboard, the existing calculations now compute a unified, deterministic $R_{\text{final}}$ score:

$$R_{\text{final}} = \text{clamp}\big((1 - w \cdot q) \cdot R_{\text{base}} + (w \cdot q) \cdot R_{\text{visual}},\, 0,\, 100\big)$$

All existing user-facing contracts (`dynamicRiskClass`, `dynamicExposureCategory`, route composite penalty scores, and map layers) now consume $R_{\text{final}}$ directly.

## 2. Exactly Which Existing Scoring Functions Were Changed

### A. Road Segment Scoring Path
- **File:** `src/lib/roads/service.ts`
- **Method:** `evaluateSegmentRisk(segment: RoadSegmentRecord, observations: RoadObservationEvidence[]): EvaluatedRoadSegmentRisk`
- **What Changed:**
  - **$R_{\text{base}}$ Calculation:** Computes baseline score $[0, 100]$ from multi-cell maximum susceptibility (`Math.round(segment.maxCellSusceptibility * 100)`) plus physical underpass depression offset ($+20$ pts).
  - **Spatial Snapping & Proximity:** Calls `imageEvidenceService.getRoadImageSummary` with road segment spatial coordinates (`{ start: segment.startCoord, end: segment.endCoord }`) to bound association to $\le 25\text{m}$.
  - **Fusion Execution:** Fuses $R_{\text{base}}$ with $R_{\text{visual}}$ using `RiskFusionEngine.fuseRisk(...)`, factoring reliability $q$ (recency, quality, uncertainty, and distance).
  - **Dynamic Risk Classification:** Driven directly by $R_{\text{final}}$:
    - $R_{\text{final}} \ge 66 \implies \text{'high'}$
    - $R_{\text{final}} \ge 33 \implies \text{'moderate'}$
    - $R_{\text{final}} < 33 \implies \text{'low'}$
  - **Output Fields:** Attaches `riskScore` ($R_{\text{final}}$), `baseRiskScore` ($R_{\text{base}}$), `visualRiskScore` ($R_{\text{visual}}$), `visualReliability` ($q$), `visualWeight` ($w \cdot q$), and `fusionReason`.

### B. Building Exposure Scoring Path
- **File:** `src/lib/buildings/service.ts`
- **Methods:** `evaluateFootprintExposure` & `queryBuildings`
- **What Changed:**
  - **$R_{\text{base}}$ Calculation:** Computes baseline building score $[0, 100]$ from `maxCellSusceptibility * 100`.
  - **Strictly Localized Association:** Replaced cell-wide image querying with strict centroid-based radius matching ($\le 35\text{m}$). Photos taken $> 35\text{m}$ away inside the same 250m cell no longer bleed across unrelated buildings.
  - **Fusion Execution:** Fuses $R_{\text{base}}$ with building visual impact score $R_{\text{visual}}$ (plinth/doorstep inundation) via `RiskFusionEngine`.
  - **Dynamic Exposure Category:** Driven directly by $R_{\text{final}}$:
    - $R_{\text{final}} \ge 66 \implies \text{'high\_catchment'}$
    - $R_{\text{final}} \ge 33 \implies \text{'moderate\_catchment'}$
    - $R_{\text{final}} < 33 \implies \text{preserved modeled category}$
  - **Output Fields:** Attaches `riskScore`, `baseRiskScore`, `visualRiskScore`, `visualReliability`, `visualWeight`, and `fusionReason`.

### C. Route Evaluation & Selection Penalties
- **File:** `src/lib/roads/service.ts`
- **Method:** `evaluateCandidateRoutes(candidates: CandidateRouteInput[], cityId: string): Promise<RouteComparisonResult>`
- **What Changed:**
  - Traversed segments supply their updated $R_{\text{final}}$-driven `dynamicRiskClass` into route exposure ratios (`highRiskDistanceM`, `moderateRiskDistanceM`).
  - Active verified flooded images add visual impedance penalties ($+25$ to $+30$ pts).
  - Automatically shifts routing recommendation to `'avoid'` and explains the specific visually confirmed flooded segments.

### D. Image Service Spatial Indexing
- **File:** `src/lib/images/service.ts`
- **Methods:** `getRoadImageSummary` and `getBuildingImageSummary`
- **What Changed:**
  - Added Haversine metric distance computation.
  - Strict distance thresholds: $\le 25\text{m}$ for road corridors, $\le 35\text{m}$ for building parcels.
  - Returns `distanceMeters` on every summary record for transparent UI inspection.

## 3. Mathematical Parameters & Scientific Guardrails

| Parameter | Symbol | Range | Default / Derivation | Hydrometeorological Role |
| :--- | :--- | :--- | :--- | :--- |
| **Base Risk** | $R_{\text{base}}$ | $[0, 100]$ | $\text{round}(S_{\text{max}} \times 100) + \text{offsets}$ | Verifiable baseline terrain runoff propensity. |
| **Visual Risk** | $R_{\text{visual}}$ | $[0, 100]$ | Deterministic mapping from visual condition | Severe inundation: 95; Flowing: 65; Ponding: 35; Dry: 10. |
| **Reliability** | $q$ | $[0.0, 1.0]$ | $q_{\text{dist}} \times q_{\text{time}} \times q_{\text{qual}} \times \text{conf}$ | Degrades with distance, age, and blur. $q=0$ for historical photos. |
| **Visual Weight** | $w$ | $[0.0, 1.0]$ | Configurable default: $0.35$ | Bounded maximum visual influence (provisional heuristic). |
| **Dry Dampening** | $w_{\text{eff}}$ | $[0.0, 1.0]$ | $w \times 0.25$ when $R_{\text{visual}} < R_{\text{base}}$ | Prevents a dry road spot from overriding high rainfall danger. |
| **Safety Floor** | - | - | $R_{\text{final}} \ge 0.85 \cdot R_{\text{base}}$ | A dry image cannot reduce modeled risk by more than 15%. |

## 4. Verification Evidence & Test Results

The dedicated suite in `tests/unit/images/p31-risk-fusion.test.ts` validates all required edge cases:

1. **Monotonicity:**
   - Evaluated $R_{\text{base}} = 40$ against escalating conditions:
     - `none` ($R_{\text{vis}} = 10$) &rarr; $R_{\text{final}} = 38$
     - `curb_ponding` ($R_{\text{vis}} = 35$) &rarr; $R_{\text{final}} = 39$
     - `flowing_surface_water` ($R_{\text{vis}} = 65$) &rarr; $R_{\text{final}} = 48$
     - `deep_standing_water` ($R_{\text{vis}} = 85$) &rarr; $R_{\text{final}} = 54$
     - `submerged` ($R_{\text{vis}} = 95$) &rarr; $R_{\text{final}} = 57$
   - Monotonic increase strictly verified.
2. **Sensitivity:**
   - With $R_{\text{base}} = 30$, $R_{\text{visual}} = 90$, $w = 0.4$:
     - $q = 0.00 \implies R_{\text{final}} = 30$
     - $q = 0.25 \implies R_{\text{final}} = 36$
     - $q = 0.50 \implies R_{\text{final}} = 42$
     - $q = 0.75 \implies R_{\text{final}} = 48$
     - $q = 1.00 \implies R_{\text{final}} = 54$
   - Smooth linear scaling confirmed.
3. **Stale Evidence Guardrail:**
   - Ingested 3-year-old survey photo &rarr; $q = 0.0 \implies R_{\text{final}} = R_{\text{base}} = 45$ exactly.
4. **Geographic Assignment & Non-Bleeding:**
   - Ingested photo $14\text{m}$ from building centroid &rarr; matched and factored into risk score.
   - Ingested photo $190\text{m}$ away in the same 250m cell &rarr; completely rejected from building summary.
5. **Missing Data Guardrail:**
   - When no imagery exists ($q = 0$), $R_{\text{final}} = R_{\text{base}} = 75$ (never zeroed out).
6. **Asymmetric Dry Override Guardrail:**
   - $R_{\text{base}} = 85$ (high catchment runoff) tested with dry photo ($R_{\text{visual}} = 10$, $q = 0.9$):
   - $R_{\text{final}} = 79$ (dampened; risk stays above the 85% safety floor $\ge 72$). Dry spots cannot erase catchment risk.
7. **City Isolation:**
   - Amritsar flood photo does not alter Jalandhar road risk evaluation ($R_{\text{final}} = 20$, unchanged).
