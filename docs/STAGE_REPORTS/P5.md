# Stage Report P5: Real Risk Engine, Explanations & Evaluation API

## 1. Executive Summary
Stage P5 implements the production-grade TypeScript hydrometeorological risk engine, risk explanation system, and offline evaluation API for NEXSTORM (Pilot City: Amritsar, Punjab; Secondary View: GNDU Campus).

All 47 shared cross-language test vectors pass within absolute tolerance $< 10^{-9}$. All 3 golden replay hours match historical reference outputs to the exact fourth decimal place. Canonical configuration hashing validates the frozen configuration and strictly rejects unauthorized tampering. The performance target ($51\text{ members} \times 2,500\text{ cells} \times 48\text{ hours} < 1,500\text{ ms}$) was measured at **35.88ms** (isolated) and **126.44ms** (full test runner) in Node.js v24.16.0—more than 10x faster than required.

## 5. Known Limitations & Unresolved Issues
1. Coarse Rainfall Input: Weather forecasts from Open-Meteo ERA5-Land and GFS/ECMWF ensembles operate on a ~10–25 km spatial grid, lacking hyper-local convective cloudburst resolution.
2. Proxy Topography: Susceptibility features are derived from open Copernicus DEM and OSM density proxies without underground municipal stormwater drainage network telemetry.
3. News-Derived Validation: Hotspot ground truth is sourced from curated regional news reporting which exhibits reporting bias toward major commercial corridors.
4. Deterministic Replay: Historical reanalysis archive series are single deterministic paths; ensemble confidence intervals are truthfully unavailable.
