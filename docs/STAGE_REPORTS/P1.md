## 3. Risk Core Engine Architecture & Formulas

### 3.1 Rainfall Trigger Index ($\text{RTI}$)
Rainfall Trigger Index represents dynamic meteorological pressure normalized against historical thresholds:
$$\text{RTI} = \max_{w \in \{1, 3, 6, 24\}} \left( \frac{R_w}{T_w} \right) + 0.15 \times \left( \frac{A_{72}}{100} \right)$$
Where:
- $R_w$: Trailing rainfall sum over window $w \in \{1\text{h}, 3\text{h}, 6\text{h}, 24\text{h}\}$.
- $T_w$: Threshold parameter for window $w$ (Default Amritsar thresholds: $T_1 = 35\text{mm}$, $T_3 = 55\text{mm}$, $T_6 = 80\text{mm}$, $T_{24} = 120\text{mm}$).
- $A_{72}$: Antecedent 72-hour rainfall in millimeters (capped to non-negative values).

RTI Bands:
- `LOW`: $\text{RTI} < 0.60$
- `MODERATE`: $0.60 \le \text{RTI} < 1.00$
- `HIGH`: $1.00 \le \text{RTI} < 1.50$
- `SEVERE`: $\text{RTI} \ge 1.50$

### 3.2 Static Susceptibility Band ($S$)
Static susceptibility index $S \in [0, 1]$ represents terrain slope, depression, imperviousness, and drainage density:
- `LOW`: $S < 0.33$
- `MODERATE`: $0.33 \le S < 0.66$
- `HIGH`: $S \ge 0.66$

### 3.3 12-Cell Risk Decision Matrix
$$\text{RiskClass}(S, \text{RTI}) = \begin{cases}
\text{LOW} & \text{if } \text{RTI} = \text{LOW} \text{ (for any } S \text{)} \\
\text{LOW} & \text{if } S = \text{LOW} \land \text{RTI} \in \{\text{MODERATE}, \text{HIGH}\} \\
\text{MODERATE} & \text{if } S = \text{LOW} \land \text{RTI} = \text{SEVERE} \\
\text{MODERATE} & \text{if } S = \text{MODERATE} \land \text{RTI} \in \{\text{MODERATE}, \text{HIGH}\} \\
\text{HIGH} & \text{if } S = \text{MODERATE} \land \text{RTI} = \text{SEVERE} \\
\text{MODERATE} & \text{if } S = \text{HIGH} \land \text{RTI} = \text{MODERATE} \\
\text{HIGH} & \text{if } S = \text{HIGH} \land \text{RTI} \in \{\text{HIGH}, \text{SEVERE}\}
\end{cases}$$

### 3.4 Triangular Hyetograph
For synthetic scenarios with peak intensity $P$ (mm/h) and duration $D$ (hours), the rainfall profile over $t \in [0, 47]$ is modeled as a symmetric triangle peaking at $t_{\text{peak}} = \lfloor D/2 \rfloor$:
$$r(t) = \begin{cases}
P \cdot \left(1 - \frac{|t - t_{\text{peak}}|}{t_{\text{peak}} + 1}\right) & \text{if } 0 \le t \le D \\
0 & \text{if } t > D
\end{cases}$$

## 4. API Request & Response Contracts

### `POST /api/scenario`
- **Request Body:**
  ```json
  {
    "cityId": "amritsar",
    "scenario": {
      "peakMm1h": 70,
      "durationH": 6,
      "antecedentMm72h": 20
    }
  }
  ```
- **Validation Rules:**
  - `cityId`: Must exist in city registry (`amritsar`). Unrecognized cities return HTTP 400.
  - `peakMm1h`: Number, $0 \le \text{peakMm1h} \le 300$.
  - `durationH`: Integer, $1 \le \text{durationH} \le 48$.
  - `antecedentMm72h`: Number, $0 \le \text{antecedentMm72h} \le 500$.
- **Success Response (HTTP 200):**
  ```json
  {
    "success": true,
    "data": {
      "cityId": "amritsar",
      "mode": "scenario",
      "timestamp": "2026-10-14T...",
      "scenario": {
        "peakMm1h": 70,
        "durationH": 6,
        "antecedentMm72h": 20
      },
      "rti": 1.73,
      "rtiBand": "severe",
      "displayedClass": "high",
      "confidence": "unavailable",
      "classDistribution": {
        "low": 0.28,
        "moderate": 0.35,
        "high": 0.37
      },
      "cellCount": 4332,
      "cells": [
        {
          "cellId": "cell-0",
          "susceptibility": 0.42,
          "riskClass": "moderate",
          "sBand": "moderate",
          "rtiBand": "severe"
        }
      ],
      "provenance": {
        "dataSource": "synthetic",
        "model": "triangular_hyetograph_rti_v1",
        "generatedAt": "2026-10-14T...",
        "isSimulated": true,
        "isDerived": true,
        "disclaimer": "DEMO DATA — Research Prototype. Not verified for emergency or operational decision-making."
      }
    }
  }
  ```

### `GET /api/risk`
- **Parameters:** `?city=amritsar&mode=scenario&peakMm1h=70&durationH=6&antecedentMm72h=20`
- **Modes:**
  - `mode=scenario`: Delegates directly to scenario evaluation engine.
  - `mode=live` or `mode=replay`: Returns HTTP 501 `NOT_IMPLEMENTED` with `{ "error": { "code": "NOT_IMPLEMENTED", "message": "Mode 'live' is planned for P2." } }`.

## 5. Synthetic City Dataset Specifications

- **Location:** Amritsar, Punjab, India
- **Bounding Box:** $31.55^\circ\text{ N}$ to $31.72^\circ\text{ N}$, $74.80^\circ\text{ E}$ to $74.95^\circ\text{ E}$
- **Cell Count:** 4,332 contiguous rectangular grid cells (~250m on a side, $57 \times 76$ grid).
- **Susceptibility Equation:** Seeded 2D harmonic wave combined with distance-to-center depression function:
  $$S(x, y) = 0.5 + 0.25 \sin(6\pi x) \cos(5\pi y) + 0.15 \sin(12\pi x) - 0.2 \left( (x - 0.5)^2 + (y - 0.5)^2 \right)$$
  Normalized strictly to $[0.02, 0.98]$.
- **Storage:** Static asset in `public/data/cities/amritsar/susceptibility.geojson` (1.3 MB).
