## 1. Executive Summary & Governance Directive

Per the Hackathon Starter Operating Directive (Rule 0 / AGENTS.md):
> *"THE STARTER SERVES THE FUTURE PRODUCT. THE FUTURE PRODUCT DOES NOT SERVE THE STARTER."*

This audit rigorously evaluates all modules and toolkits in the Hackathon Starter against the target architecture of **NEXSTORM**:
- Next.js 16 App Router, React 19, TypeScript strict, Tailwind CSS v4.
- Reusable UI primitives, charts, visualization, and maps (`src/components/geo/`, `src/lib/geo/`, `src/components/visualization/`, `src/lib/visualization/`).
- Validated API clients, resilience, retry, circuit breaker, caching, and snapshots (`src/lib/api/`, `src/lib/cache/`, `src/lib/validations/`).
- Static geospatial data consumption (`public/data/`) generated by the Python hydrological/weather pipeline.
- Rainfall-driven waterlogging-risk engine, provenance, uncertainty estimation, model evaluation, historical replay, alerts, and offline demo support.
